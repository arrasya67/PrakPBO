## 2. Latar Belakang dan Deskripsi Sistem

### 2.1 Latar Belakang
Dalam pengembangan perangkat lunak, data yang hanya disimpan di dalam memori (variabel) akan hilang seketika program ditutup atau komputer dimatikan. Untuk menjaga persistensi data, dibutuhkan mekanisme *Input/Output* (I/O) yang memungkinkan program untuk menyimpan data ke dalam media penyimpanan sekunder, salah satunya adalah file teks. 

Tugas ini dibuat untuk mensimulasikan proses pengolahan nilai siswa di mana data yang dimasukkan oleh pengguna (guru/admin) melalui konsol akan dihitung secara otomatis, disimpan sebagai laporan ke dalam file `laporan_nilai.txt`, dan kemudian dibaca kembali untuk ditampilkan sebagai bentuk verifikasi.

### 2.2 Deskripsi Sistem
Sistem ini berjalan secara *procedural/fungsional* (berfokus pada alur eksekusi di dalam `main` method). Alur kerja program adalah sebagai berikut:
1. Pengguna memasukkan jumlah siswa yang akan diinput.
2. Program melakukan *looping* untuk meminta input nama dan nilai masing-masing siswa.
3. Program secara otomatis menentukan status kelulusan (Nilai ≥ 70 = Lulus).
4. Program menghitung total nilai, rata-rata, serta jumlah siswa lulus dan tidak lulus.
5. Seluruh data siswa dan ringkasan kelas dituliskan ke dalam file `laporan_nilai.txt`.
6. Program membaca kembali file tersebut dan menampilkannya di layar konsol.

## 3. Tujuan Pembelajaran dan Ruang Lingkup

### 3.1 Tujuan Pembelajaran
Implementasi ini bertujuan untuk mempraktikkan konsep:
*   **Input Console:** Membaca input pengguna menggunakan `Scanner`.
*   **Penulisan File (File Writing):** Menggunakan `FileWriter` dan `BufferedWriter` untuk menyimpan data ke media penyimpanan.
*   **Pembacaan File (File Reading):** Menggunakan `FileReader` dan `BufferedReader` untuk membaca data baris demi baris.
*   **Resource Management:** Menerapkan struktur `try-with-resources` agar *stream* file tertutup secara otomatis.
*   **Exception Handling:** Menangani kemungkinan kesalahan I/O menggunakan `try-catch` (`IOException`).
*   **Pemformatan Angka (Locale):** Menggunakan `Locale.US` untuk menyeragamkan format angka desimal agar tidak terjadi *error* pada sistem operasi lokal.

### 3.2 Ruang Lingkup Fungsional
*   Menerima input nama (`String`) dan nilai (`double`).
*   Menentukan kelulusan siswa secara *real-time* di dalam *looping*.
*   Menulis file teks yang dilengkapi garis pemisah untuk estetika laporan.
*   Menghitung akumulasi rata-rata kelas dan total kelulusan.
*   Menampilkan isi file kembali ke layar konsol.

### 3.3 Batasan Sistem
Berdasarkan *source code*, beberapa batasan sistem ini adalah:
*   Data lama di dalam file akan tertimpa (ditimpa ulang) setiap kali program dijalankan, karena `FileWriter` secara *default* membuka file dalam mode *overwrite*.
*   Belum ada penanganan khusus jika pengguna memasukkan nilai desimal menggunakan koma (`,`), meskipun `Locale.US` sudah membantu, kesalahan input tipe data bisa menyebabkan `InputMismatchException` yang belum ditangkap.
*   Tidak ada fitur untuk menghapus atau mengedit data siswa tertentu karena pendekatan program masih sekuensial (satu arah).

## 5. Pemetaan Konsep OOP dan Fitur Bahasa Java
Meskipun pendekatan yang digunakan bersifat prosedural, program ini menggunakan berbagai fitur bahasa Java yang kuat:
*   **Class dan Method**: Menggunakan `class Main` sebagai wadah utama dan `public static void main` sebagai titik eksekusi.
*   **Objek Scanner**: `Scanner input = new Scanner(System.in)` digunakan untuk membaca aliran *input* dari *keyboard*.
*   **File I/O Streams**: Implementasi `BufferedWriter`, `FileWriter`, `BufferedReader`, dan `FileReader` untuk manipulasi data persisten.
*   **Exception Handling**: Blok `try-catch` untuk menangkap `IOException` (kesalahan Input/Output).
*   **Resource Management (Java 7+)**: Penggunaan *try-with-resources* (contoh: `try (BufferedWriter writer = ...)`) yang secara otomatis menutup *file stream* saat blok selesai, tanpa perlu memanggil `.close()` secara manual.
*   **Pemformatan String**: `String.format()` untuk membatasi jumlah desimal pada *output* rata-rata.
*   **Kelas Locale**: Menjamin format angka desimal tetap menggunakan titik (`.`), mengabaikan pengaturan *region* komputer.

## 6. Bedah Kode Sumber

### 6.1 Inisialisasi Scanner dan Locale
```java
Scanner input = new Scanner(System.in);
input.useLocale(Locale.US);
```
**Penjelasan**: `Locale.US` sangat penting. Jika tidak diatur, Java akan mengikuti format lokal komputer. Pada sistem operasi yang menggunakan bahasa Indonesia, tanda desimal adalah koma (`,`). Jika pengguna mengetik `80.5`, program bisa *crash* (melempar `InputMismatchException`). `Locale.US` memastikan titik (`.`) selalu dikenali sebagai desimal.

### 6.2 Penulisan File dengan try-with-resources
```java
try (BufferedWriter writer = new BufferedWriter(
        new FileWriter("laporan_nilai.txt"))) {
```
**Penjelasan**: `FileWriter` membuka koneksi ke file. `BufferedWriter` membungkusnya agar penulisan teks lebih efisien (disimpan di memori *buffer* dulu sebelum ditulis ke disk). Struktur `try (...)` adalah fitur *resource management* modern: Java akan otomatis memanggil `writer.close()` pada akhir blok `try`, bahkan jika terjadi *error*.

### 6.3 Looping Input dan Logika Kelulusan
```java
for (int i = 1; i <= jumlahSiswa; i++) {
    // ...
    if (nilai >= 70) {
        status = "Lulus";
        jumlahLulus++;
    } else {
        status = "Tidak Lulus";
        jumlahTidakLulus++;
    }
}
```
**Penjelasan**: *Looping* dilakukan sebanyak jumlah siswa. Operator `>=` memastikan siswa dengan nilai pas 70 tetap dinyatakan "Lulus". Variabel kounter `jumlahLulus` dan `jumlahTidakLulus` bertambah secara dinamis.

### 6.4 Membaca File Baris Demi Baris
```java
try (BufferedReader reader = new BufferedReader(
        new FileReader("laporan_nilai.txt"))) {
    String baris;
    while ((baris = reader.readLine()) != null) {
        System.out.println(baris);
    }
}
```
**Penjelasan**: `reader.readLine()` akan mengembalikan baris teks pertama, lalu kursor pembaca pindah ke baris selanjutnya. Saat sudah mencapai akhir file (EOF - End of File), method ini mengembalikan nilai `null`, yang membuat perulangan `while` berhenti secara natural.

## 9. Analisis Hasil Pengujian dan Output Sistem
Berdasarkan eksekusi program dengan 5 data siswa:

### 9.1 Skenario Pengujian (Uji Batas/Boundary Testing)
*   **Budiman (80)**: Lulus (di atas 70).
*   **Raihan Hanan (70)**: Lulus (menguji batas persis angka 70, membuktikan operator `>=` berjalan benar).
*   **Erwin Ramadhan (79)**: Lulus.
*   **Gustavo Almaida (69)**: Tidak Lulus (selisih 1 poin dari batas).
*   **Viscara (68)**: Tidak Lulus.

### 9.2 Analisis Output File (`laporan_nilai.txt`)
```text
==================================
        LAPORAN NILAI SISWA
==================================
Nama   : Budiman 
Nilai  : 80.0
Status : Lulus
----------------------------------
Nama   : Raihan Hanan 
Nilai  : 70.0
Status : Lulus
----------------------------------
Nama   : Erwin Ramadhan
Nilai  : 79.0
Status : Lulus
----------------------------------
Nama   : Gustavo Almaida
Nilai  : 69.0
Status : Tidak Lulus
----------------------------------
Nama   : Viscara 
Nilai  : 68.0
Status : Tidak Lulus
----------------------------------

========== RINGKASAN ==========
Rata-rata nilai : 73.20
Jumlah Lulus    : 3
Jumlah Tidak Lulus : 2
```

**Verifikasi Matematika**:
*   Total Nilai: `80 + 70 + 79 + 69 + 68 = 366`.
*   Rata-rata: `366 / 5 = 73.20` (Sesuai).
*   Jumlah Lulus: `3`, Tidak Lulus: `2` (Sesuai).

### 9.3 Temuan Edge Case (Temuan Kasus Tepi)
1.  **Pembagian dengan Nol**: Jika `jumlahSiswa` diinput dengan angka 0, maka `totalNilai / jumlahSiswa` akan menghasilkan `NaN` (Not a Number). Program sebaiknya mengecek `if (jumlahSiswa > 0)` sebelum menghitung rata-rata.
2.  **Penimpaan Data (Overwrite)**: Karena `new FileWriter("laporan_nilai.txt")` tidak ditambahkan parameter `true` (*append*), file lama akan tertimpa setiap kali program dijalankan.
3.  **Input Spasi pada Nama**: Penggunaan `input.nextLine()` sangat tepat di sini, sehingga nama seperti "Raihan Hanan" (mengandung spasi) berhasil dibaca secara utuh tanpa terpotong.
