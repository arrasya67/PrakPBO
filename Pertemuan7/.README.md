## 2. Latar Belakang dan Deskripsi Sistem

### 2.1 Latar Belakang
Dalam pengembangan perangkat lunak, pengolahan data yang baik tidak hanya berfokus pada hasil akhir, tetapi juga pada **validasi input** dan **penanganan kesalahan (error handling)**. Program yang tangguh (*robust*) harus mampu mencegah *crash* ketika pengguna memasukkan data yang salah (seperti NIM berisi huruf atau nilai di luar batas). 

Tugas ini dibuat untuk mengimplementasikan struktur data berbasis objek (OOP) yang ketat, memanfaatkan *Collection* (`ArrayList`), mekanisme *Custom Exception*, *Assertion*, serta penyimpanan data permanen (*File I/O*). Program ini mensimulasikan proses penginputan nilai mahasiswa oleh dosen/admin dan mencetak laporan nilai ke dalam file teks.

### 2.2 Deskripsi Sistem
Program berjalan di antarmuka baris perintah (CLI). Alur kerjanya dimulai dengan meminta pengguna memasukkan jumlah mahasiswa. Kemudian, program melakukan *looping* untuk meminta input Nama, NIM, dan Nilai. Jika ada input yang tidak valid (misal NIM kosong atau nilai > 100), program akan menolak input tersebut dan meminta pengguna mengulanginya. Setelah semua data valid, program akan menampilkan rekapitulasi nilai ke layar dan menyimpannya ke dalam file `laporan_nilai.txt`.

## 3. Tujuan Pembelajaran dan Ruang Lingkup

### 3.1 Tujuan Pembelajaran
Implementasi ini bertujuan untuk mempraktikkan konsep:
*   **Object-Oriented Programming (OOP):** Pembuatan *Class*, *Object*, *Encapsulation*, dan *Package*.
*   **Exception Handling:** Penggunaan `try-catch`, `throw`, dan pembuatan *Custom Exception* (`NilaiInvalidException`).
*   **Assertion:** Penggunaan keyword `assert` untuk mengecek asumsi internal program (dijalankan dengan flag `-ea`).
*   **Collections:** Penggunaan `ArrayList` untuk menyimpan kumpulan objek dinamis.
*   **File I/O:** Penulisan data ke file teks menggunakan `BufferedWriter` dan `FileWriter` dengan *try-with-resources*.
*   **String & Locale Formatting:** Manipulasi string (`.trim()`, `.toUpperCase()`) dan format desimal menggunakan `Locale.US`.

### 3.2 Ruang Lingkup Fungsional
*   Input jumlah mahasiswa dengan validasi angka bulat positif.
*   Input Nama, NIM (divalidasi hanya angka), dan Nilai (divalidasi rentang 0-100).
*   Perhitungan otomatis Grade (A, B, C, D) dan Status Kelulusan (Lulus/Tidak Lulus).
*   Perhitungan total nilai, rata-rata kelas, dan jumlah kelulusan.
*   Menampilkan data ke konsol dan menyimpannya ke file `laporan_nilai.txt`.

### 3.3 Batasan Sistem
*   Program **hanya bisa menulis (write)** ke file, belum ada fitur untuk membaca kembali file tersebut ke dalam program.
*   Program bersifat *one-way* (hanya input). Belum ada fitur untuk mengedit atau menghapus data mahasiswa tertentu setelah dimasukkan.
*   File `laporan_nilai.txt` akan selalu ditimpa (*overwrite*) setiap kali program dijalankan ulang.

## 6. Bedah Kode Sumber

### 6.1 Custom Exception: `NilaiInvalidException.java`
```java
public class NilaiInvalidException extends Exception {
    public NilaiInvalidException(String pesan) {
        super(pesan);
    }
}
```
**Penjelasan:** Class ini mewarisi (`extends`) class `Exception` bawaan Java. Fungsinya agar kita bisa melempar pesan *error* yang spesifik terkait nilai mahasiswa, bukan sekadar *error* umum.

### 6.2 Class `Mahasiswa.java`
```java
public Mahasiswa(String nama, String nim, double nilai)
        throws NilaiInvalidException {
    this.nama = nama.trim().toUpperCase();
    validasiNim(nim);
    this.nim = nim.trim().toUpperCase();
    
    if (!Double.isFinite(nilai) || nilai < 0 || nilai > 100) {
        throw new NilaiInvalidException(
            "Nilai harus berada antara 0 sampai 100!"
        );
    }
    this.nilai = nilai;
}
```
**Penjelasan:** Constructor ini tidak hanya mengisi atribut, tetapi juga melakukan **validasi ketat**. Nama dan NIM di-`trim()` (menghapus spasi) dan di-`toUpperCase()` (menjadi huruf besar). Jika nilai yang dimasukkan `NaN` (Not a Number), kurang dari 0, atau lebih dari 100, program akan melempar (`throw`) exception yang akan ditangkap oleh `Main.java`.

```java
public static void validasiNim(String nim) {
    String nimBersih = nim.trim();
    assert !nimBersih.isEmpty() : "NIM tidak boleh kosong!";

    if (nimBersih.isEmpty()) {
        throw new IllegalArgumentException("NIM tidak boleh kosong!");
    }
    for (int i = 0; i < nimBersih.length(); i++) {
        if (!Character.isDigit(nimBersih.charAt(i))) {
            throw new IllegalArgumentException("NIM hanya boleh berisi angka!");
        }
    }
}
```
**Penjelasan:** Terdapat penggunaan ganda untuk pengecekan string kosong. Pertama menggunakan `assert` (hanya jalan jika di-compile dengan flag `-ea`). Kedua menggunakan `if` standar agar program tetap aman meskipun *assertion* dimatikan. Perulangan `for` mengecek setiap karakter menggunakan `Character.isDigit()`.

### 6.3 Class `Main.java` (Input Validation Loop)
```java
while (true) {
    System.out.print("NIM  : ");
    nim = input.nextLine();
    try {
        Mahasiswa.validasiNim(nim);
        break; // Keluar loop jika valid
    } catch (AssertionError | IllegalArgumentException e) {
        System.out.println("Kesalahan: " + e.getMessage());
    }
}
```
**Penjelasan:** Penggunaan `while(true)` berfungsi agar program terus meminta input NIM jika terjadi kesalahan. Jika `validasiNim` berhasil, perintah `break` akan menghentikan loop. Jika gagal, `catch` akan menangkap error dan menampilkan pesannya tanpa membuat program *crash*.

### 6.4 Class `Main.java` (Penyimpanan ke File)
```java
try (BufferedWriter writer = new BufferedWriter(
        new FileWriter("laporan_nilai.txt"))) {
    writer.write("======================================");
    writer.newLine();
    // ... (proses menulis data)
} catch (IOException e) {
    System.out.println("Gagal menyimpan laporan: " + e.getMessage());
}
```
**Penjelasan:** Struktur `try-with-resources` memastikan file otomatis ditutup (*close*) setelah selesai ditulis, mencegah kebocoran memori. Data ditulis baris demi baris menggunakan `writer.write()` dan `writer.newLine()`.

## 8. Panduan Kompilasi dan Eksekusi Program

### 8.1 Kompilasi
Karena program menggunakan *package* (`app` dan `model`), kompilasi harus dilakukan dari direktori utama (folder induk yang berisi folder `app` dan `model`).
```bash
javac -d out app/*.java model/*.java
```
*(Perintah ini akan mengompilasi file Java dan menaruh hasil `.class`-nya ke dalam folder `out`)*.

### 8.2 Eksekusi Program (PENTING)
Untuk mengaktifkan fitur **Assertion** (`-ea`), jalankan program dengan perintah berikut:
```bash
java -ea -cp out app.Main
```
*Jika dijalankan tanpa `-ea`, blok `assert` tidak akan dieksekusi, namun program tetap aman karena ada validasi `if` standar.*

## 9. Analisis Hasil Pengujian dan Output Sistem

Berdasarkan *output* yang diberikan, program diuji dengan 5 mahasiswa dan berhasil menangani berbagai macam *error*:

1. **Skenario Gagal (Validasi NIM - Assertion):**
   Saat `Budiman` memasukkan NIM kosong (hanya spasi), program mendeteksi melalui *assertion* dan menampilkan `Kesalahan: NIM tidak boleh kosong!`. Program tidak *crash*, melainkan mengulang input NIM.
2. **Skenario Gagal (Validasi NIM - Alfanumerik):**
   Saat diinput `L032501`, program mendeteksi karakter 'L' bukan angka dan memunculkan `Kesalahan: NIM hanya boleh berisi angka!`.
3. **Skenario Gagal (Validasi Nilai):**
   Saat `Jeki` memasukkan nilai `120`, `NilaiInvalidException` berhasil dicegat dan meminta input ulang. Jeki kemudian memasukkan `75` dan data berhasil disimpan.
4. **Skenario Sukses & Transformasi Data:**
   Nama yang diinput dengan spasi (misal: `Budiman `) atau huruf kecil, otomatis di-*trim* dan diubah menjadi huruf besar (`BUDIMAN`) saat dicetak di rekap.
5. **Perhitungan Matematika:**
   Total nilai: `85 + 90 + 75 + 60 + 89 = 399`. Rata-rata: `399 / 5 = 79.80`. Jumlah Lulus: 4, Tidak Lulus: 1. Semua perhitungan **Sesuai**.

### 9.2 Temuan Edge Case (Kelemahan Kode)
*   **Penyimpanan File Ditimpa:** Karena `new FileWriter("laporan_nilai.txt")` tidak menggunakan parameter `true` (append), data lama akan tertimpa setiap kali program dijalankan. Jika ingin menyimpan histori, gunakan `new FileWriter("laporan_nilai.txt", true)`.
*   **Nilai Desimal (Koma vs Titik):** Meskipun menggunakan `Locale.US` untuk *output*, input menggunakan `Double.parseDouble()`. Jika pengguna mengetik `80,5` (pakai koma), program akan memicu `NumberFormatException` dan menganggapnya sebagai huruf. Pengguna diharuskan mengetik `80.5` (pakai titik).
